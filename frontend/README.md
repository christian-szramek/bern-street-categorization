# Frontend

## Prerequisites

- Node.js 25.8.0
- npm 11.11.0

1. Navigate to the frontend directory:

```sh
foo@bar:~$ cd frontend
```

2. Install the dependencies:

```sh
foo@bar:~$ npm install
```

3. Start the development server:

```sh
foo@bar:~$ npm run dev
```

4. Open the frontend in the browser e.g.: _http://localhost:5173/_
