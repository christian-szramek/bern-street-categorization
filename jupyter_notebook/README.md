# Python Jupyter Notebook Setup

1. Install and setup the dependencies:

```sh
foo@bar:~$ sudo apt install python3
```

```sh
foo@bar:~$ sudo apt install python3-pip
```

```sh
foo@bar:~$ sudo apt install python3-venv
```

2. Navigate to the Python Jupyter Notebook directory:

```sh
foo@bar:~$ cd jupyter_notebook
```

3. Active the virtual environment:

```sh
foo@bar:~$ source .venv/bin/activate
```

4. Start the Python Jupyter Notebook:

```sh
foo@bar:~$ jupyter notebook
```

5. Open the Python Jupyter Notebook in the browser e.g.: _http://localhost:8888/notebooks/bern-street-categorization.ipynb_
