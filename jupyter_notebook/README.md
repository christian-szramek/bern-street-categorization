# Python Jupyter Notebook Setup

1. Install and setup Python:

```sh
sudo apt install python3 python3-pip python3-virtualenv
```

2. Navigate to the Python Jupyter Notebook directory:

```sh
cd jupyter_notebook
```
3. Create the virtual environment:

```sh
virtualenv venv
```

4. Active the virtual environment:

```sh
source venv/bin/activate
```

5. Install the dependencies:

```sh
pip install -r requirements.txt
```

6. Start the Python Jupyter Notebook:

```sh
jupyter notebook
```

7. Open the Python Jupyter Notebook in the browser e.g.: _http://localhost:8888/notebooks/bern-street-categorization.ipynb_
